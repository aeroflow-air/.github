# AeroFlow Air

AeroFlow Air is a fictional airport, built as an Azure developer platform showcase: decisions, golden paths and services, built in public by Tony Joanes. Nothing here serves real traffic.

## Repositories

- [platform-handbook](https://github.com/aeroflow-air/platform-handbook): decision records (ADRs) with a validator on every PR, plus the conventions the platform follows.
- [template-dotnet-service](https://github.com/aeroflow-air/template-dotnet-service): golden-path .NET 8 service template with health checks, structured logging, ProblemDetails, a Dockerfile and tests.
- [aeroflow-workflows](https://github.com/aeroflow-air/aeroflow-workflows): reusable GitHub Actions workflows for .NET CI and decision-record validation, pinned by tag.
- [svc-flight-status](https://github.com/aeroflow-air/svc-flight-status): flight lifecycle service in functional-style C#, created from the template. Not deployed yet.
- [svc-gate-allocation](https://github.com/aeroflow-air/svc-gate-allocation): gate allocation service in functional-style C#, created from the template. Not deployed yet.
- [site-customer](https://github.com/aeroflow-air/site-customer): the public site and engineering blog, built with Astro and deployed to GitHub Pages.
